# odyssey — corpus for the Slipbox example

Public-domain source texts about Homer's *Odyssey* — translations, commentary,
essays, and retellings (~1858–1930) — used by the `odyssey/` example slipbox in
[slipboxmd/slipbox](https://github.com/slipboxmd/slipbox).

This repo is consumed as a **git submodule** at `examples/odyssey/sources/`. Clone
the main repo with `--recursive` (or `git submodule update --init`) to get these.

All texts are public domain (Project Gutenberg + Internet Archive). Provenance and
ids are in [SOURCES.md](SOURCES.md).
